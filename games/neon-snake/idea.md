# Idea — Neon Snake

## Pitch

improve neon-snake game to follow the game-forge skill standard, adding more levels, improve ui, ux, sound effect, etc. Make the best snake game

## Design brief

A 2D top-down snake game on a fixed 20×20 grid with neon aesthetics. The player steers a glowing snake to collect food, growing longer each time while avoiding the walls and its own tail. Speed increases as the score climbs. The core innovation is multiple levels with distinct layouts, obstacles, and scoring mechanics — beyond the flat endless board. Controls use arrow keys or WASD (keyboard) and swipe (touch), with pause, guide, scores, and mute panels. The neon palette (green accents on dark background, pulsing glow effects) is retained and expanded. Sound effects (eat, die, level-up) and a richer UI (animated transitions, particle effects, difficulty selection) make this feel polished rather than minimal.

**Reference:** classic Snake with modern neon visual polish and multi-level progression.
